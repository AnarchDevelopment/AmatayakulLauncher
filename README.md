## Amatayakul Launcher

### Amatayakul Launcher es un launcher open source con múltiples funciones, hecho para Minecraft: Windows 10 Edition Beta (Build 0.15.10.0)

## Funciones

### Inyector de DLLs

Inyecta automáticamente DLLs al juego, siendo su principal función (inyectar el cliente Amatayakul al juego).

<img width="500" alt="image" src="https://github.com/user-attachments/assets/5d997522-874b-49d4-9683-8d5ac0a4b6c2" />

### Instalador de texturas

Instala automáticamente texturas `.apk` al juego.

<img width="500" alt="image" src="https://github.com/user-attachments/assets/21cfa7fc-79f0-4faf-beb2-1e68fd89e3a5" />

### Tweaks (mejoras)

* **Fullbright** — deja la luz del juego siempre al máximo.
* **Shaders** — mejora la iluminación del juego con shaders HLSL.
* Se planea agregar más cosas.
