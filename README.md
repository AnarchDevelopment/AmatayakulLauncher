# Amatayakul Launcher

**Amatayakul Launcher** es un launcher **open source** para **Minecraft: Windows 10 Edition Beta (Build 0.15.10.0)**.

Su objetivo es facilitar la instalación y configuración del juego, ofreciendo herramientas como **inyección de DLLs, instalación de texturas y diferentes tweaks gráficos**.

---

## ✨ Funciones

### 💉 Inyector de DLLs

Permite inyectar automáticamente DLLs en el juego.

Su función principal es cargar **Amatayakul Client** directamente al iniciar Minecraft.

[AmatayakulDLL en GitHub](https://github.com/AnarchDevelopment/AmatayakulDLL?utm_source=chatgpt.com)

### 🛠️ Tweaks

Incluye diferentes mejoras y modificaciones para el juego:

* **Fullbright** — mantiene la iluminación del juego al máximo.
* **Shaders** — mejora la iluminación mediante shaders **HLSL**.
* **Más próximamente** — se planean añadir nuevos tweaks y opciones de personalización.

## 📦 Compatibilidad

Actualmente, Amatayakul Launcher está desarrollado específicamente para:

* **Minecraft: Windows 10 Edition Beta**
* **Build 0.15.10.0**
* **Windows**

> ⚠️ Otras versiones de Minecraft pueden no ser compatibles.
